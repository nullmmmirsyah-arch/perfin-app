Desktop Dashboard Review

Temuan & prioritas perbaikan — semua aspek (Layout, Components, UX, Code)

🔴 P1 — Critical (Harus diperbaiki)

1.1 Empty State QuickAdjust inconsistent

Saat belum ada budget, QuickAdjust menampilkan card kosong dengan pesan "Set up budgets to adjust them here" — tapi card tetap memakan ruang grid. Sebaiknya hidden/remove dari layout atau jadi inline prompt untuk buat budget.

Lokasi

components/dashboard/QuickAdjust.tsx:128-143

1.2 Privacy Mode tidak konsisten

TransactionListGrouped di desktop tidak menerima isPrivacyMode prop — tidak ada masking amount. RecurringSummary, TrendChart, MonthlyComparison sudah handle. Ini inkonsistensi data exposure.

Lokasi

app/dashboard/page.tsx:262 — TransactionListGrouped tidak dikasih isPrivacyMode

1.3 QuickAdjust range slider mentok di 50%-150%

Slider budget cuma bisa adjust antara 50% s/d 150% dari alokasi awal. Kalau pengen set ke 0 atau double, gabisa. Ini terlalu restriktif untuk power user.

Lokasi

components/dashboard/QuickAdjust.tsx:159-160 — min/max hardcoded

🟠 P2 — High Priority

2.1 Tidak ada Key Metrics / Summary Baris Atas

Desktop tidak menampilkan ringkasan cepat seperti Total Balance, Total Budget, Unassigned Cash di baris atas. Mobile punya MobileHeroSummary, tapi desktop langsung lompat ke grid. Pengguna desktop perlu info cepat tanpa scroll.

2.2 TrendChart hanya 3 bulan default

Tidak ada kontrol untuk mengubah rentang waktu (3mo, 6mo, 12mo). Pengguna tidak bisa melihat tren jangka panjang. getMonthlyTrends dipanggil tanpa argumen months.

Lokasi

components/dashboard/TrendChart.tsx:39-41

2.3 DailyOperationsCard — Budget rows tidak ada visual hierarchy

Semua kategori budget tampil dalam list sederhana. Tidak ada grouping (by type, by urgency), tidak ada collapsing untuk kategori yang on-track. Pengguna dengan banyak kategori akan kewalahan.

2.4 QuickAdjust tidak sinkron real-time

Setelah apply, nilai slider kembali ke original karena state lokal tidak sync dengan server. Perlu refresh page untuk melihat perubahan. Seharusnya setelah apply sukses, nilai langsung update.

Lokasi

components/dashboard/QuickAdjust.tsx:92-126 — handleApply tidak update local state

2.5 RecurringSummary tidak ada action button untuk mark paid

Mobile punya tombol mark paid inline di MobileRecurringRow. Desktop hanya view-only. Pengguna harus navigasi ke halaman Recurring untuk mark paid.

🟡 P3 — Medium Priority

3.1 Loading state hanya skeleton generik

2 skeleton cards untuk 2 kolom. Tidak ada skeleton spesifik per komponen (DailyOperationsCard skeleton, TrendChart skeleton, dll). Pengguna tidak tahu komponen mana yang sedang loading.

3.2 Tidak ada error state per komponen

Query Convex bisa gagal. Saat ini tidak ada error boundary / error state. Hanya skeleton loading indefinite.

3.3 2-column grid tidak responsive dalam ukuran layar

Grid pake md:grid-cols-2 — dari 768px sampai 2560px+ selalu 2 kolom. Di layar lebar (1440px+) terasa terlalu stretched. Di layar kecil (768-900px) terasa sempit.

3.4 Belum ada interaksi antar komponen

Klik kategori di DailyOperationsCard navigate ke halaman detail. Tidak ada filtering/highlighting lintas komponen (misal: klik kategori → TrendChart highlight kategori tsb). Pengalaman desktop lebih statis.

3.5 MonthlyComparison hanya compare month-to-month

Tidak bisa bandingkan periode kustom (misal: bulan ini vs rata-rata 3 bulan terakhir). Insight jadi terbatas.

⚪ P4 — Low Priority / Enhancement

4.1 Tidak ada fitur export/cetak

Dashboard desktop tidak punya opsi export PDF, print layout, atau share snapshot.

4.2 Animasi Framer Motion minimal

Hanya fade in/up animation via staggerContainer. Tidak ada micro-interactions (hover scale, smooth transitions, layout animations).

4.3 Keyboard navigation tidak optimal

QuickAdjust slider bisa dioper dengan keyboard, tapi DailyOperationsCard tabs tidakaccessible dengan keyboard.
