Design — Group 3 (P3)

3.1 Loading States per Komponen

Problem: Semua loading diwakili 2 skeleton cards generik — user tidak tahu komponen mana yang loading.

Fix: Buat skeleton spesifik per komponen di components/skeletons.tsx:

  • DailyOperationsCardSkeleton — card dgn 3 tab placeholder + 3 baris progress bar
  • TrendChartSkeleton — card dgn bar chart placeholder (3 bars palsu)
  • MonthlyComparisonSkeleton — card dgn big number placeholder + 3 baris kategori
  • RecurringSummarySkeleton — card kecil dgn 2 baris teks
  • QuickAdjustSkeleton — card dgn 2 slider placeholder

Dashboard page render skeleton spesifik per slot, bukan 2 generic cards.

File: skeletons.tsx (tambah 5 skeleton baru), page.tsx (ganti DashboardCardSkeleton per slot).

3.2 Error States

Problem: Kalau query gagal, user lihat skeleton loading terus (indefinite).

Fix: Ubah pattern dari:

summary === undefined ? <Skeleton /> : ...

Jadi:

if (summary === undefined) return <Skeleton />
if (summary === null) return <ErrorState message="..." onRetry={...} />
// render data

Buat ErrorState component generic (reuse EmptyState dari shadcn dengan tambahan tombol Retry). Convex return null saat query error — jadi undefined = loading, null = error.

File: Buat ErrorState di components/ui/. Update tiap komponen dashboard handle error case.

3.4 Cross-Component Interaction

Problem: Klik kategori di DailyOperationsCard → navigasi ke halaman detail. Tidak ada interaksi antar komponen di dashboard.

Fix: Approach quick fix: Gunakan custom event (seperti yang sudah dipake untuk receivables: PERFIN_SETTLE_RECEIVABLE).

  • Klik kategori di DailyOperationsCard → dispatch event PERFIN_FILTER_CATEGORY dgn categoryId
  • TrendChart listen event → highlight bars untuk kategori tsb
  • MonthlyComparison listen event → filter biggest changes untuk kategori tsb
  • Klik lagi → unhighlight (toggle)

Pattern sama persis dengan yang sudah ada untuk receivable settlement — proven pattern di codebase ini.

File: DailyOperationsCard (tambah dispatch di BudgetRow link click), TrendChart & MonthlyComparison (tambah useEffect listener).

3.5 MonthlyComparison — Custom Period

Problem: Hanya compare bulan ini vs bulan lalu.

Fix: Minimal: Tambah ViewToggle kecil di card header: vs Last Month | vs Avg (3mo). State compareMode: 'last' | 'avg3'.

Mode "vs Avg (3mo)" ambil months: 4 dari query, hitung rata-rata bulan 2-4, compare dengan bulan 1 (current). Tampilkan sebagai perbandingan yang sama.

File: MonthlyComparison.tsx — tambah mode toggle, logic average comparison.

Data: ambil 4 bulan → current = trends[0], average = avg(trends[1], trends[2], trends[3])
Visual: sama seperti existing — "% change" + top 3 category changes vs average
