Section 4: Rencana Implementasi per Fase

Agar setiap fase bisa di-commit & push tanpa break

Fase 1: Foundation

⏱ Komitmen terpisah · ✅ Aman di-push · Tidak ada perubahan layout
● Rename Cash → Balance tab
● "Total Liquid Cash" → "Total Balance"
● Ganti dots → text badges (On Track/Watch/Too Fast)
● Update copy: "~RpX/day" → "Spend up to RpX today"
● Update BudgetCard.tsx (halaman budgets) juga
● Tambah "X days remaining" di Budget Left
File: DailyOperationsCard.tsx, BudgetCard.tsx, finance-utils.ts

Fase 2: Mobile Daily View

⏱ Terbesar · Layout mobile berubah total · Komponen baru:
➕ DailyGuidance — status + rekom + historical context
➕ BudgetSummary — Budget Left + remaining days
➕ BudgetAttentionList — kategori terurut + badges
➕ TodaySpending — transaksi hari ini + allowance progress
➕ BalanceSummary — aggregated + drill-down
➕ LentSummary — compact version
Layout mobile: Carousel dihapus → scroll vertical dengan komponen di atas. Data dari Convex yang sudah ada (belum perlu query baru untuk MVP).

Fase 3: Desktop Planning & Desktop Layout

⏱ Komponen baru + query Convex baru untuk trend
➕ TrendChart — monthly spending comparison
➕ MonthlyComparison — insight teks (this month vs last)
➕ WhatIfSimulator — budget adjustment simulation
➕ BudgetQuickEdit — inline limit editor
Layout desktop: 2-column grid dengan kiri = daily ops, kanan = planning. Query baru: getMonthlyTrends di Convex untuk data chart.

Fase 4: Polish + Positive Reinforcement

⏱ Sentuhan terakhir — coaching layer
➕ Celebration messages ("Great job!")
➕ Historical context di DailyGuidance (last week)
➕ Transisi & animasi
➕ Fallback copy untuk empty states
➕ iOS-like haptics & polish

💡 Setiap fase selesai → bisa push. Fase 1 tidak merusak UI. Fase 2 hanya ubah mobile. Fase 3 hanya ubah desktop. Fase 4 hanya polish.
