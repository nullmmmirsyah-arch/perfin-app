Pendekatan Arsitektur Dashboard

Semua opsi pakai data yang sudah ada + query Convex baru untuk trend

A

Monolitik — Enhance Existing

DailyOperationsCard diperbesar + Daily Guidance di-inline

Pro

  • Minim refactor
  • Cepat delivery

Kontra

  • File makin besar (510+ baris)
  • Sulit bedain Mobile vs Desktop
  • Sulit di-test
B

Modular — Komponen Baru

Setiap section jadi komponen independen, composing di page

DailyGuidance, BudgetSummary, BudgetAttentionList, TrendChart, WhatIfSimulator

Pro

  • Clean separation
  • Mobile/Desktop layout beda
  • Testable & reusable

Kontra

  • Refactor besar
  • Lebih banyak file
C

Hybrid — Cards + Widgets

DailyOperationsCard di-slim, DailyGuidance & TrendWidget di luar card

Card tetap, tambah widget coaching di page level

Pro

  • Kompromi aman
  • Bertahap bisa migrasi ke modular

Kontra

  • Bisa inconsistent
  • Masih ada duplication

💡 Rekomendasi saya: B (Modular). Ini selaras dengan fase yang dipilih (Mobile vs Desktop beda layout), mengurangi kompleksitas file besar, dan paling mudah untuk tambah fitur coaching bertahap.
