Fase Structure: Mana yang Cocok?

Dengan target MVP = Coach Ringan + adaptif long-term

1

PRD + Coaching Layer

4 fase PRD tetap, masing-masing + coaching:

  • Fase 1: Foundation + copy coaching
  • Fase 2: Daily Guidance + historical context
  • Fase 3: Budget Focus + positive reinforcement
  • Fase 4: Transactions visual hierarchy
2

Restructure: Desktop vs Mobile First

Fase dipisah berdasarkan behavior:

  • Fase 1: Foundation (badges, copy, naming)
  • Fase 2: Mobile-first daily view (Daily Guidance + quick actions)
  • Fase 3: Desktop planning view (trends, what-if, calendar)
  • Fase 4: Polish + positive reinforcement layer
3

Hybrid

Mulai dengan PRD + coaching, lalu ada fase khusus Desktop planning

  • Fase 1: PRD Phase 1 + 2 (Foundation + Daily Guidance + coaching)
  • Fase 2: PRD Phase 3 + 4 (Budget + Transactions + coaching)
  • Fase 3: Desktop Planning Mode (BARU — trend, kalender, what-if)
