✅ Keuntungan

  • Mobile & Desktop bisa layout beda total
  • Fitur coaching gampang ditambah incremental
  • Testing per komponen, bukan per card raksasa
  • Budget tab di card lama bisa dihapus setelah migrasi

⚠️ Risk

  • Total file komponen naik (tapi tiap file kecil)
  • Butuh data baru dari Convex untuk trend/history
  • DailyOperationsCard harus di-slim / di-retain utk backward compat
